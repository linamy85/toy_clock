# 時鐘森林大冒險：兒童時鐘辨識與時間解謎學習遊戲

為國小學童設計的可愛森林動物主題時鐘學習遊戲，透過擬真動態指針時鐘、單選互動問答、清脆動聽的 Web Audio 音效與手動點擊語音朗讀，引導孩子從基礎認識指針到精準分鐘與時間計算，建立紮實的時間觀念與成就感。

## User Review & Critical Decisions

> [!IMPORTANT]
> 依據您在提問中的反饋，我們已確認三大核心設定：
> 1. **難度階梯**：聚焦於「學齡小學進階（精準分鐘與時間計算）」，設計包含：整點/半點複習、15分鐘區間、5分鐘刻度、精準到每一分鐘辨識，以及「經過時間與推算」挑戰題。
> 2. **視覺主題**：採用「奇幻森林動物派對風」，溫馨亮麗的森林綠草色調，搭配森林樹屋時鐘與可愛動物夥伴（貓頭鷹博士、小松鼠助手、兔子時間精靈），生動活潑且具親和力。
> 3. **聲音回饋**：以純清脆的合成提示音效（答對叮咚歡呼、答錯溫和提示、時鐘滴答聲、連擊星星音）為主，並在每一題與時鐘旁提供「🔊 聽聽看」按鈕，調用瀏覽器語音合成（Web Speech API）親切朗讀標準中文時間（如「現在是下午三點四十二分」），讓孩子主動聆聽練習。

- **倒數計時器**：每題可由使用者自訂開啟或關閉倒數（預設關閉以降低初學挫折，提供 15秒 / 30秒 / 45秒 可選挑戰模式）。
- **指針輔助細節開關**：時鐘盤面可一鍵切換「顯示分鐘刻度數字 (5, 10, 15...)」、「彩色指針區分（時針藍色粗短、分針紅色細長）」、「彩虹時間色塊（幫助理解小時扇形區間）」，配合不同年級學習需求自由啟閉。

## 1. Overview & Core Concept

- **What It Does**: 提供互動式 SVG 擬真雙指針/三指針時鐘，動態生成各類時間辨識題目與單選題選項。結合答題連擊獎勵、倒數計時挑戰、星星勳章收集、以及自由探索模式（可拖曳時鐘指針，觀察指針聯動並即時語音朗讀）。
- **Target Audience**: 國小一至四年級學童、學齡前大班進階幼童、家長與國小低年級數學教師。
- **Key Value**: 解決傳統時鐘教材靜態枯燥、分針與時針連動關係難以理解的痛點，結合可愛森林動物獎勵動畫與自適應難度，讓時間辨識學習變得像玩闖關遊戲一樣有趣。

### Visual Identity & Theme

- **Aesthetic Direction**: 奇幻森林動物派對（Whimsical Forest Party）。大自然溫暖色調、手繪質感 SVG 樹屋木質時鐘、圓潤清晰的大字體、親切的動物小助手動畫。
- **Color Palette & Discipline (60-30-10)**:
  - **60% 畫布基底**: 柔和森林草地奶白與淡木色背景（`#F8FAF5` / `#EDF5E8`）。
  - **30% 結構與時鐘盤面**: 象牙白時鐘表面（`#FFFFFF`）、樹木暖褐色框架（`#6E5136`）、柔和森林綠邊界（`#2D5A27`）。
  - **10% 焦點色彩**:
    - 時針與小時標記：清晰海軍藍（`#2563EB`）
    - 分針與分鐘標記：活潑珊瑚紅（`#E11D48`）
    - 秒針（可選開關）：金黃色（`#D97706`）
    - 正確與獎勵反饋：翠綠（`#16A34A`）與琥珀金星（`#F59E0B`）
- **Typography**: 
  - 標題與時鐘數字：俐落清晰圓潤的字體（`Outfit` / `Plus Jakarta Sans`，時鐘數字使用加粗等寬對稱字體），時鐘數字大且清晰。
  - 正文與說明：閱讀舒適的高辨識度 Sans-Serif 字體。
- **Anti-Slop Restraint**: 不使用廉價霓虹紫漸層、不放無意義的裝飾假徽章，按鈕使用直覺清晰的中文字樣（「開始冒險」、「下一題」、「聽聽看」、「重來一次」）。

## 3. Key Product Decisions & Trade-Offs

- **Decision 1: 時鐘指針聯動精確度**
  - *Chosen Approach*: 嚴格遵循真實機械時鐘的齒輪連動公式：時針角度 = `(小時 % 12) * 30 + (分鐘 / 60) * 30`；分針角度 = `分鐘 * 6`。在小學進階題中，分針走到 45 分時，時針必須逼近下一個小時，這正是小學生最容易看錯時針的關鍵教學重點！
  - *Why*: 真實反映鐘面物理連動，培養精準讀鐘能力，避免坊間玩具軟體時針只停留在整數刻度導致誤導。
- **Decision 2: 聲音系統架構（純 Web Audio API 合成音效 + Web Speech API）**
  - *Chosen Approach*: 使用 Web Audio API 程式化合成清脆水晶叮咚、連擊泛音、勝利號角與柔和木魚滴答聲，無需外部音檔下載，零延遲且永不破音；語音朗讀採用瀏覽器原生 `window.speechSynthesis`（繁體/標準中文），點擊即朗讀。
  - *Why*: 零外部依賴、極致流暢、無跨域封鎖問題，並給予家長/學童完全自主的開關靜音控制。
- **Decision 3: 階梯式難度與題庫演算法**
  - *Level 1 (入門整點與半點)*: 1:00, 2:30 等，分針只在 12 或 6。
  - *Level 2 (15 分鐘區間)*: 3:15, 7:45 等，理解一刻鐘與三刻鐘。
  - *Level 3 (5 分鐘刻度)*: 5, 10, 20, 25 分等，掌握「乘法 5 的倍數」與指針對應。
  - *Level 4 (精準到每分鐘)*: 8:23, 10:47 等，觀察時鐘細小刻度與時針微偏移。
  - *Level 5 (經過時間與推算題)*: 附帶小問題（如：「小松鼠烤蛋糕需要 35 分鐘，現在鐘面上是 2:10，出爐是幾點幾分？」）。

## 5. Verification Plan

1. **時鐘指針角度計算與渲染驗證**：測試各時間點（如 1:59、12:00、6:30、10:48）之時針與分針角度是否完全符合齒輪連動規律。
2. **選項生成邏輯驗證**：確保干擾選項合理（如分針看成時針、時針提早進位等典型學童錯誤思維選項），且 4 個選項無重複。
3. **Web Audio 與 Web Speech API 測試**：驗證音效與語音朗讀在不同瀏覽器環境下點擊觸發皆平滑無報錯。
4. **倒數計時與狀態切換測試**：計時歸零時提供溫和提示並揭曉解題指引，不造成學童壓力。
5. **編譯檢驗**：執行 `compile_applet` 確認無 TypeScript 或打包錯誤。
